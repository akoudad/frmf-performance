# Metric definitions

## Goals
Count `REGULAR` + `PENALTY`.
Exclude `OWN_GOAL`.

## Red cards
Count recorded `RED` card events literally.

## Yellow cards
Count recorded `YELLOW` card events literally.

## Injuries
Count recorded injury events.
This does not mean the player is currently injured.

## Match results
Use the reported home/away scores from the source data.

## Currently unavailable
- Pass completion / best passer: no pass data
- Assists: assist fields are null
- Suspensions: no official sanction/eligibility data
- Best player: no agreed definition yet
